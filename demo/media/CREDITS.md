# Demo media

All files are MIT, same as the project: original artwork made for LibreFunnel, drawn as code in `demo/art.ts` (no
photos, no music). The store, its products and its buyers are fictional.

- `*.webp` and `vsl-demo.mp4`: `bun run demo-art` writes them again. It needs `rsvg-convert`, `ffmpeg` and the fonts
  Fraunces, Inter and Caveat (SIL Open Font License, Google Fonts) installed.
- `vsl-demo.vtt`: captions for `vsl-demo.mp4`, written for LibreFunnel.
