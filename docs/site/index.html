LibreFunnel
Código aberto · MIT · github.com/ToledoSDL/librefunnel

A operação de venda online inteira num processo só.

Tracker, VSL, checkout, área de membros, recuperação de carrinho, robô de WhatsApp e painel de vendas. Em vez de sete assinaturas que não se falam, um app que sobe com docker compose up -d numa VPS grátis.

“Não faria mais sentido todos criarem uma só?”: a pergunta no X que deu origem a este repositório, em 13/11/2026.

Ver o código Ver como funciona
git clone https://github.com/ToledoSDL/librefunnel && cd librefunnel cp .env.example .env && docker compose up -d --build # passo a passo completo no README
O que ele substitui

Sete ferramentas, sete bancos de dados. Ou um.

Tracker de atribuição/t + Meta CAPI
Player e página de VSL/v/<produto>
Checkout/c/<produto>
Área de membros/m (link no e-mail)
Recuperação de carrinho/admin
Robô estilo Manychat/api/webhooks/whatsapp
Painel de vendas/admin
→

Uma pessoa, uma linha do tempo

Cada ferramenta é um módulo que grava eventos sobre o mesmo visitante. Por isso “qual anúncio vendeu?” deixa de ser uma integração entre cinco painéis e vira uma consulta no mesmo banco.

visitante ─┬─ evento ─ pedido ─ membro ─ mensagem
A espinha de eventos

Acompanhe a Ana do anúncio até a aula.

Cada passo abaixo é o que acontece de verdade no código, com a linha que entra no banco. Toque num passo ou use os botões. 

    
            
    
            
    
            
    
              
              
            
    
          
    
        
    
      
    

      
    
        Pix sem gateway
        
    O checkout não cobra taxa porque não passa por ninguém.
    
        
    
          O código Pix copia e cola é um texto no padrão do Banco Central, com um dígito verificador no fim. O
          librefunnel monta esse texto direto para a sua chave. O teste confere o resultado contra o exemplo do próprio
          manual do BR Code:
        
    
        
    
          00020126580014br.gov.bcb.pix0136123e4567-e12b-12d1-a456-4266554400005204000053039865802BR5913Fulano
          de Tal6008BRASILIA62070503***63041D3D
        
    
        
    
          Você confere o extrato e libera no painel, de graça. Se preferir confirmação automática, liga o Mercado Pago
          (0,99% por venda) e o acesso sai sozinho quando o Pix cai.
        
    
      
    

      
    
        Por dentro
        
    Poucos arquivos, cada um com um domínio.
    
        
    
          
    
            src/lib/orders.ts
            
    
              Pedido, preço, Pix (BR Code com CRC16), pagamentos, reembolso e expiração. O dinheiro é conferido pelo
              valor recebido.
            
    
          
    
          
    
            src/lib/messages.ts
            
    
              Fila de e-mail e WhatsApp com novas tentativas, recuperação de carrinho, robô por palavra-chave e opt-out.
            
    
          
    
          
    
            src/lib/tracking.ts
            
    Origem do visitante (primeiro e último clique) e envio da venda para a Meta Conversions API.
    
          
    
          
    
            src/app/
            
    
              As telas e o painel, onde você edita produtos, aulas, mensagens de recuperação e respostas do robô, sem
              mexer em código.
            
    
          
    
        
    
      
    

      
    
        O que ainda não faz
        
    Limites, ditos antes.
    
        
      
          
    • 
            Sem Mercado Pago, o Pix estático não avisa sozinho que foi pago: você confere o extrato e libera no painel.
          
      • 
          
    • 
            O WhatsApp usa o seu número pela Evolution API, que não é oficial: envio em massa pode bloquear o número,
            por isso há limite diário.
          
      • 

          
    • 
            Um processo por loja: o limite de tentativas fica na memória do processo, então cada réplica teria o seu
            próprio limite.
